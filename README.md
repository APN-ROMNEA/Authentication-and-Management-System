## Instructions :books:
### 1. Registration :book::pen:
***You need to fill the information correctly in each requirment***
    - You need to fill your firstname, last name and username. (username can't be duplicated)
    - Password must contain number, uppercase and lowercase letter, and special character at least 8 digits.
    `Example`
    ![Example](./register.jpg)
  

### 2. Login:lock::key:
***You need to fill the information correctly in each requirment***
    - You have to enter username that you have registered and your password correctly. (becareful with attempt, you would be banned temporary if you enter too many wrong information).
    `Example: You enter too many wrong password!!`
    ![Example](./login.jpg)
    - For the verify code, you can input with both lowercase and uppercase. (With no space).
    - In the retype and resend code, you will have 3 attempt for both method. But after 3 attempt of retype, you can reset attempt by using a brand new code in resend method or you can leave if you want. 
    
### 3. Password Recovery:sos::key:
***You need to fill the information correctly in each requirment***
    - If you lost your password, you can simply change the password by using username that you have registered before in `Password Recovery`.
    - If you enter wrong username, the system will ask you to register, retype or leave the page. but if you enter wrong username 3 times, you will be kicked out from recovery page to main page.
    `Example`
    ![Example](./P_R.jpg)
